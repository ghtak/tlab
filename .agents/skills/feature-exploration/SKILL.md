# 기능 구상

사용자가 제공한 목적·지원 범위·제약에서 기능 목록과 간단한 흐름을 제안하고 대화로 다듬는다.

## 참조 범위

- 시작할 때 [기능 구상 가이드](../../../docs/agent/feature-exploration/index.md)를 읽고 적용한다. 경로는 이 `SKILL.md`의 디렉터리를 기준으로 해석한다.
- 이 스킬과 가이드 외의 스킬·저장소·내부 문서·외부 자료는 자동으로 참조하지 않는다. 사용자가 참조를 요청하면 지정한 범위에서 활용한다.
- 앞서 확인한 구현 정보도 사용자가 이번 구상의 전제로 지정하지 않으면 판단 근거로 사용하지 않는다.

## 수행

1. 명시된 지원 범위와 나중에 정할 사항을 짧게 정리하고, 현재 정보로 만들 수 있는 기능 목록·흐름의 초안을 먼저 제시한다.
2. 기능명·한 줄 설명을 중심으로 포함 범위와 후보·보류 항목을 구분한다. 열린 질문을 좁혀가며 추가·통합·분리와 범위 조정을 진행한다.
3. 상세 흐름·정책·예외·검증 조건과 구현 선택은 후속 단계로 남기고, 사용자가 요청하면 해당 범위로 이어간다.

결과는 기본적으로 대화에서 유지한다. 별도 문서 저장이나 구현 조사로 자동 전환하지 않는다.
