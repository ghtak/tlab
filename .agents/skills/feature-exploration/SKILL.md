# 기능 구상

전체 기능의 범위와 연결을 유지하고, 개별 주제를 별도 대화로 넘길 수 있게 정리한다.

## 참조 범위

- 시작할 때 [기능 구상 가이드](../../../docs/agent/feature-exploration/index.md)를 읽고 적용한다. 경로는 이 `SKILL.md`의 디렉터리를 기준으로 해석한다.
- 이 스킬과 가이드 외의 자료는 자동 참조하지 않는다. 사용자 요청이나 대상·목적을 설명한 뒤 받은 동의에 따라 지정된 범위만 확인한다.
- 앞서 확인한 구현 정보도 사용자가 이번 구상의 전제로 지정하지 않으면 근거로 사용하지 않는다.

## 수행

1. 목적·지원 범위·제약·나중에 정할 사항을 파악하고 기능 목록·연계성·간단한 흐름을 제안한다.
2. 필요성·대안·누락을 대화로 검토하고, 포함·후보·보류와 열린 질문을 갱신한다.
3. 상세 요구사항·DB·JWT 등으로 논의가 확장되면 관련 기능에 질문과 의존 관계를 남기고 별도로 다룰 범위를 정리한다. 사용자가 상세 논의를 요청하면 해당 주제에 필요한 맥락을 전달한다.
4. 개별 논의의 결과를 돌려받으면 핵심 결정과 기능 간 영향만 개요에 반영한다.

결과는 기본적으로 대화에 유지하고, 문서 저장은 요청받은 경우에 수행한다. 다른 스킬·자료를 미리 읽거나 모든 하위 주제를 한 대화에서 상세화하지 않는다.
