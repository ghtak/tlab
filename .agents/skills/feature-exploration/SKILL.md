# 기능 구상

논의 대상의 목적·책임·기능 범위·관계를 중심으로 정리하고, 상세 내용은 해당 요구사항·설계 문서에 둔다. 개별 사례는 공통 기능으로 묶되 사용자가 제시한 의미와 제약은 보존한다.

## 참조 범위

- 시작할 때 [기능 구상 가이드](../../../docs/agent/feature-exploration/index.md)를 읽고 적용한다. 경로는 이 `SKILL.md`의 디렉터리를 기준으로 해석한다.
- 이 스킬과 가이드 외의 자료는 자동 참조하지 않는다. 사용자 요청이나 대상·목적을 설명한 뒤 받은 동의에 따라 지정된 범위만 확인한다.
- 앞서 확인한 구현 정보도 사용자가 이번 구상의 전제로 지정하지 않으면 근거로 사용하지 않는다.

## 수행

1. 논의 대상의 목적·범위·제약을 파악하고 필요한 기능과 할 일의 목록을 제안한다.
2. 필요성·대안·누락을 검토하며 항목·관계·열린 질문을 조정한다. 변경 제안은 상위 수준에서 무엇을 추가·제외·이동할지와 이유를 먼저 설명한다. 큰 범위와 개별 기능에 같은 방식을 적용한다.
3. 세부 정책·예외·처리 흐름·구현 방식은 현재 범위나 책임 경계 판단에 필요하거나 사용자가 상세화를 요청한 경우에 다룬다. 그 외의 상세 논점을 질문이나 할 일로 과도하게 확장하지 않는다. 필요한 논점은 관련 항목과 문서에 연결한다.

결과는 대화에 유지하고, 저장을 요청받으면 해당 기능과 가까운 문서에 정리한다. 별도 진행 상태 관리나 하위 결과 수집 절차를 만들지 않는다. 다른 스킬·자료는 미리 읽지 않는다.
