# 코딩 지침

코드를 신규 구현하거나 수정할 때 다음 원칙을 따른다.

- 관련 코드가 있다면 기존 동작과 설계 의도를 확인하고 존중한다.
- 구현 전에 관련 구조와 기존 기능을 확인해 같은 책임의 코드를 중복 작성하지 않는다.
- 기존 기능을 재사용할 때 입력 조건, 결과, 오류 처리와 부작용이 요구사항에 맞는지 확인한다. 차이가 있다면 무리하게 통합하거나 불필요한 추상화를 추가하지 않는다.
- 요구사항을 만족하는 데 필요한 범위만 수정한다.
- 증상을 우회하지 말고 확인된 근본 원인을 수정한다.
- 같은 전제에 기반한 수정이 반복해서 실패하면 추가 수정 전에 그 전제를 확인한다.
- 구현하거나 수정한 부분을 실제로 실행해 검증한다. 실행할 수 없으면 그 이유와 미검증 범위를 보고한다.
- 도움이 될 것이라는 가정만으로 코드를 추가하지 않는다. 확인된 요구사항과 검증된 동작에 필요한 코드만 남긴다.
