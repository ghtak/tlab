## 공유 변경과 통합 결정

| 대상 | 구현 책임과 통합 기준 |
| --- | --- |
| `tlab/src/config.rs` | `Loader`와 `from_file`, `from_env`, `env_prefix`, `load`, `try_deserialize` 구현. 상세 계약은 개별 계획 참조. |
| `tlab/src/lib.rs` | `pub mod config;` 추가. 기존 `Error`·`Result` 공개와 `add` 유지. |
| `tlab/Cargo.toml`, `Cargo.lock` | 설계의 config·serde 구성 적용 후 Cargo 해석 결과로 잠금 파일 갱신. |
| `tlab/tests/config.rs` | 공개 API, 오류, 임시 파일, 자식 프로세스 환경변수 테스트를 함께 검증. |
| `tlab/src/error.rs`, `tlab/tests/error.rs` | 기존 오류 계약과 테스트 재사용. 새 오류 변형이나 동등한 오류 테스트를 중복 작성하지 않음. |

설계에 따라 파싱·병합은 외부 `config`에 위임하고, 같은 이름의 자체 모듈과는 `::config` 경로로 구분한다. 환경변수 단독 사용은 `from_env`로 제공하며 빈 소스용 생성자나 범용 설정 계층은 추가하지 않는다.-`추론함`

`tracing::Config`, 개별 모듈 설정 타입, 파일 생성·갱신·감시, CLI 소스, 여러 파일 병합은 범위 밖이다. 테스트 데이터의 tracing 키가 실제 tracing 모듈 의존성으로 이어지지 않도록 한다.-`측정함`

공개 API·소스 우선순위·오류 계약이 구현 중 바뀌어야 한다면 요구사항과 설계 및 개별 계획의 영향을 먼저 확인하고 근거를 기록한다. 후속 구현 커밋은 `impl-001`에 필요한 변경만 대상으로 한다.-`추론함`

## 검증과 완료 판단

검증은 [개별 계획의 완료 조건](implementation/impl-001.md#구현-계획)에 따라 R1~R9를 공개 API로 확인한다. 환경변수는 설계대로 자식 프로세스에 전달하고 부모 프로세스 환경은 변경하지 않는다. 임시 파일은 각 테스트에서 독립 생성·정리한다.-`추론함`

공통 검증의 작업 위치는 저장소 루트 `C:/Users/tlab/works/tlab`이다. 아래 명령은 후속 실행 계획이다.

```powershell
cargo fmt --check
cargo test -p tlab
cargo clippy -p tlab --all-targets -- -D warnings
```

실제 Cargo 의존성 해석, 임시 디렉터리 읽기·쓰기, 테스트 실행 파일의 자식 프로세스 실행이 필요하다. 이 환경에서 실행하지 못하면 원인과 미검증 범위를 기록하고 완료로 처리하지 않는다. 기존 오류·`add` 테스트도 함께 통과해야 한다.-`추론함`

`impl-001`의 구현, 필수 검증, 결과 기록이 끝나야 해당 항목을 완료로 바꾼다. 동일 단위가 전체 범위를 담당하므로 공통 통합 검사와 대표 문서 요약까지 마친 뒤 전체 `implementation`을 완료로 바꾼다. 커밋 기본 형식은 `feat: impl-001`이며 사용자 제외 지시가 있으면 따로 기록한다.-`추론함`

## 현재 진행과 다음 행동

사용자 지시로 [rev-03](implementation/impl-001.md#rev-03)에서 `File::from(path)` 위임을 복원했다. 파일 탐색·선택·읽기·파싱을 config에 맡기고 정확한 경로만 허용하는 추가 제약은 제거했다. R2와 설계·리뷰 판단을 현재 계약에 맞게 갱신했으며 공개 API·환경변수 계약은 유지했다.-`측정함`

복원 후 기본 테스트 9개와 부모를 통한 자식 테스트가 통과했다. fmt·전체 test·clippy 검사도 통과했다. 코드·설정 테스트는 rev-01의 내용으로 복원했으며 최신 검증과 해시는 rev-03에 기록했다. rev-01·rev-02의 구현·검증 결과는 이력으로 보존했다.-`측정함`

스테이징·커밋 없이 착수 전부터 존재한 staged 변경과 스킬·AGENTS 변경을 보존했다. 인덱스 해시도 일치한다. 이후 코드나 계약이 바뀌면 최신 검증 근거를 다시 확인한다. 별도 독립 리뷰는 수행하지 않았다.-`측정함`
