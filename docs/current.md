# 이어서 할 작업

작업 중단 시점의 스냅샷이다. 재개에 필요한 현재 상태와 다음 작업으로 갱신하며 이전 기록은 누적하지 않는다.

- **작업 문서:** [RBAC 역할·퍼미션 관리 plan](specs/rbac/manage-access/plan.md). 최신 계약은 본문과 하단의 사용자 피드백 반영 내용을 기준으로 한다.
- **현재 상태:** 01 공통 계약, 02 저장소, 03 DB resolver·공용 인가 완료. 서버 런타임 연결은 아직 없다. (확인)
- **다음 작업:** plan의 **04 로그인·갱신 JWT `user.role_ids` 발급 연결**. 로그인·명시적/웹 자동 갱신에서 서버의 최신 역할을 조회해 발급하고 실패 시 미발급을 검증한다. 담당 파일·공개 계약은 plan 참조.
- **진행 방식:** 작업별 새 herdr 오른쪽 pane에서 구현·필요한 검증·자체 점검 후 plan 하단에 결과를 남긴다. 후속 단계는 요청 범위에 맞춰 진행한다.
- **최근 기준:** `tlab::Error/Result`, 의미 구분용 타입 유지·생성 검증 없음, 임의 개수/크기 상한 없음, `#[async_trait]` resolver. 불필요한 검증·테스트를 추가하지 않는다.
- **재개 시 정리:** 정상 발급·검증된 JWT는 발급 계약을 신뢰한다. 03의 `role_ids` 양수 재검증과 관련 테스트는 최신 기준에 맞춰 정리할 사항으로 남아 있다. 가이드·plan 반영 완료, 코드 미반영. (확인)
- **검증 상태:** 03 관련 테스트 15개·clippy·fmt 통과 기록 있음. 기존 `app::tests::jwt_configuration_fails_before_connecting_to_database` 실패는 미해결이며 전체 workspace 통과 상태가 아니다. (확인: plan 기록)
